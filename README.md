DataProdukTokoMakanan

Aplikasi Data Produk Toko Makanan merupakan aplikasi untuk mengelola data produk makanan dan minuman. Aplikasi ini menyediakan fitur tambah data, pencarian, filtering, penghapusan, dan melihat detail produk.

1. Cara Menjalankan Aplikasi

Untuk menjalankan aplikasi, buka project menggunakan NetBeans, kemudian klik kanan pada project dan pilih Run.

2. Tampilan Awal Aplikasi

Setelah aplikasi berhasil dijalankan, akan muncul tampilan form seperti berikut.

Apabila jumlah data produk semakin banyak, pengguna dapat memanfaatkan fitur Search dan Filtering untuk mempermudah pencarian data.

Pencarian dapat dilakukan berdasarkan kategori maupun nama produk secara langsung.

Sebelum data dihapus, aplikasi akan menampilkan notifikasi konfirmasi untuk memastikan apakah pengguna benar-benar ingin menghapus data tersebut.
